# luffi

An original two-sail mark: saved moments catching enough wind to become things
you actually do. The curved wake is also a small smile. No mascot or stock art.

- Sea-glass mint: `#B6E8D8`
- Deep green icon ink: `#153C35`
- App canvas: `#0B0B0D`
- Soft white: `#F3F4F0`

`luffi-mark.svg` is the mark on dark surfaces. `luffi-app-icon.svg` is the opaque
launcher source. The matching Flutter painter is `lib/core/luffi_brand.dart`.
Android's adaptive foreground uses a smaller safe-zone version of these paths.

Run `node tools/render_luffi_brand.mjs` with Sharp available to regenerate all PNGs.
Alternatively pass the absolute Sharp module entry as the first argument.
App IDs, native channels, and the `.trunon` interchange format remain unchanged
so this visual rebrand preserves existing installations and saved files.
